# Sicherheit: Zugriffsgrenzen

- Repository-Zugänge sind strikt an Repository, Umgebung und Zweck gebunden.
- Ein Zugang für das persönliche Developer-Wiki darf nicht für das App-Repository verwendet werden und umgekehrt.
- Der in der App konfigurierte Wiki-Zugang darf insbesondere nicht für Bugreports oder andere Zugriffe auf das App-Repository zweckentfremdet werden.
- Verbundene GitHub-Connectoren und GitHub Apps verwenden eigene Installationsberechtigungen; auch für sie gilt das Prinzip der minimal notwendigen Rechte.
- Berechtigungen, Gültigkeitsdauer und Schreibrechte werden auf das technisch notwendige Minimum begrenzt.
